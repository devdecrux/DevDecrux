👋 About Me

I’m a Software Engineer working at a large international company, focused on designing and building scalable, maintainable backend systems. My core expertise is Java with Spring Boot, with a strong emphasis on clean architecture, clear boundaries, and long-term system evolution.

I have solid hands-on experience with SQL and NoSQL databases, including PostgreSQL and MongoDB, and I enjoy making pragmatic architectural trade-offs around data modeling, performance, and consistency.

I’ve worked with Vue.js on the frontend and I’m actively exploring Go, particularly for infrastructure tooling and performance-critical services.

I’m strongly interested in software architecture, DevOps, and infrastructure design. I run a personal homelab, where I experiment with self-hosting, virtualization, networking, automation, and private cloud-like environments — gaining real operational experience beyond pure development.

I value open source, thoughtful system design, and continuous improvement.
